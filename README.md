# 🎉 SQL-50 Solutions

Welcome! This repository holds my solutions to the **SQL-50 challenge from LeetCode** — a curated set of 50 SQL problems that build your database querying skills one problem at a time. :contentReference[oaicite:0]{index=0}

Whether you're just learning SQL or preparing for interviews, this collection is here to help you explore real problems and see working solutions.

---

## 🧠 What’s Inside

Each problem from the SQL-50 list gets:

✅ A `.sql` file with a clean, working SQL query  
✅ Practical use of SELECTs, JOINs, aggregates, filters, subqueries, window functions, and more  
✅ Comments and readable formatting so you can follow the logic step-by-step

This isn't just a dump of answers — it’s a learning journey! :contentReference[oaicite:1]{index=1}

---

## 🚀 How to Use This Repo

1. **Browse the files** — every problem is in its own file with the problem title in the name.  
2. **Try the query yourself first** — attempt your own solution before peeking!  
3. **Read the official solution** — see a clear query and compare with yours.  
4. **Learn from the style** — notice how joins and filters are structured, how complex requirements are broken down.

## 💡 Why SQL-50?

The SQL-50 list covers a wide range of key SQL concepts — from simple selects to tricky analytics queries. It’s one of the best ways to level up for:

🔹 Job interviews  
🔹 Real-world data tasks  
🔹 School projects & practice sessions

Problems get you thinking about **data relationships, aggregation logic, sorting, joins, window functions, and more** — the core building blocks of SQL mastery. :contentReference[oaicite:2]{index=2}
